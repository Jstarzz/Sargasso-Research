# Research status — 19 September 2026

## IN PROGRESS: sub-kilometre coastal forecasting feasibility

**Study:** St. Kitts Putman GPS / physics hindcast benchmark.

**Current phase:** Phase 1, currents-only retrospective hindcast using real 2018 GLORYS currents, scored against frozen Putman rolling GPS cases. The workstream integrates those currents with the trajectory integrator and runs the benchmark.

**Status provenance:** confirmed directly by Josiah Davis for this release on 19 September 2026. No active model-training run was reported.

**Publication state:** scope and status only. Results, interim metrics, tracks, and case-level outputs are withheld until the run is complete and verified. Completion must be recorded in a new reviewed experiment bundle before the automatic index/timeline publisher can expose results.

## Scope of this archive

This release is a research record, not a claim that a service is deployed. Seven-day outlooks, six-hour output intervals, sub-kilometre coastal skill, and live beach-arrival performance are not established by the completed results released here.
