# Model 3: no verified beach truth, so skill cannot be measured

## Question

Can Model 3 beach arrival skill be measured from data already on disk?

## Method

Site-by-pass cases were assembled for accepted beach geometries and labelled by available proxies.

## Result

There were no independent positives and mostly unknown outcomes.

## Interpretation

Skill is unmeasurable until verified beach observations exist.

## Limitations

- The source report is an untracked working-tree file; it is identified by SHA-256 only and has no source commit.
- Satellite-pass truth is circular with the prediction, so even the 37 filtered-empty cases are not beach truth.
- Beach geometry follows an east-facing rule on open map data, and earlier site coordinates were found to sit hundreds of metres from any accepted beach.
- No recall, false-alarm or lead-time figure is claimed.
