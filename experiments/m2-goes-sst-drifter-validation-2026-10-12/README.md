# Model 2 GOES SST-pattern motion versus drifters: not supported

## Question

Do GOES SST pattern shifts track surface drift well enough to support a motion module?

## Method

Exact six-hour GOES pairs and adjacent drifter fixes were compared tile by tile after cloud, contrast, correlation and search-boundary filters.

## Result

Coverage was low and the few accepted vectors did not agree with drifter motion.

## Interpretation

The data on hand do not justify a GOES motion module.

## Limitations

- The source report is an untracked working-tree file; it is identified by SHA-256 only and has no source commit.
- Historically exposed drifter development data, not independent confirmation.
- The tile uses the observed endpoint midpoint in hindsight; this is neither forecast skill nor serving qualification.
- Two acceptance filters (correlation and search boundary) were new preregistered rules; cloud support dominates attrition.
- The result does not show that SST-pattern co-motion is false in general.
