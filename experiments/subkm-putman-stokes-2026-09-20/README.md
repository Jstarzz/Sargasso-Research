# Sub-kilometre feasibility Phase 4: adding wave Stokes drift

## Question

Does adding wave-driven Stokes drift improve the currents plus windage transport?

## Method

The same cases were scored with and without reanalysis Stokes drift, with a 0.5 km threshold for a material difference.

## Result

Stokes drift did not help at any horizon and hurt at 24 and 48 h.

## Interpretation

Within these limits, Stokes drift is not a useful addition to the windage-corrected field.

## Limitations

- All four tracks are one July-August 2018 deployment episode near Puerto Rico; rolling cases overlap heavily, so case counts are not independent samples.
- Forcing is retrospective reanalysis (daily-mean currents, hourly reanalysis wind), not an as-issued forecast.
- No 500 m or sub-kilometre positional skill and no St Kitts validation is claimed; final claims require another deployment.
- Provider track metadata has unresolved caveats, so no period is treated as confirmed.
- The 3 percent windage was not re-estimated after adding Stokes drift, so part of it may already absorb wave drift.
- Tides are not included.
