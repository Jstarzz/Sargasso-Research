# Sub-kilometre feasibility Phase 3: dependence-aware validation of the 3 percent windage finding

## Question

Does the best windage coefficient generalize beyond the cases used to choose it?

## Method

Coefficients were selected on training tracks or an earlier period using the lowest median per horizon, and scored only on held-out tracks or a later period after a 48 h purge.

## Result

Partial support under leave-one-track-out and none under forward-time splitting.

## Interpretation

The 3 percent value should be treated as unconfirmed. More independent deployments are needed.

## Limitations

- All four tracks are one July-August 2018 deployment episode near Puerto Rico; rolling cases overlap heavily, so case counts are not independent samples.
- Forcing is retrospective reanalysis (daily-mean currents, hourly reanalysis wind), not an as-issued forecast.
- No 500 m or sub-kilometre positional skill and no St Kitts validation is claimed; final claims require another deployment.
- Provider track metadata has unresolved caveats, so no period is treated as confirmed.
- Leave-one-track-out folds share one deployment event and are not independent replications; a forward-time split of the same event is not independent either.
- Both schemes are exploratory diagnostics, not confirmatory validation.
