# Model 2 C3 recovery comparison

## Question

How did C3 compare with C and P on the Model 2 recovery cohort?

## Method

We summarize mean IoU and the reported paired intervals for 70 admitted pairs. The June-September 2026 cohort had previously been exposed, so this evaluation is recorded as a disclosed second look.

## Result

Mean IoU was 0.58914 for C3, 0.58316 for C, and 0.46878 for P. C3 minus C was +0.005985, with a 14-day interval of [-0.005435, 0.015853], which is NO_PASS. C3 minus P was +0.12036, with an interval of [0.10256, 0.14324].

## Interpretation

The comparison with C did not pass. The C3 versus P result is a secondary comparison. Neither result is independent confirmation.

## Limitations

This disclosed second look used a previously exposed June-September 2026 cohort. It is not independent, untouched, or a fresh holdout. The result does not change the selected Model 2 checkpoint or serving scope.
